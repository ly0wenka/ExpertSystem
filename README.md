# Експертна система діагностики ПК

Статичний HTML-застосунок для первинної діагностики несправностей персонального комп'ютера. Він відповідає лабораторній роботі № 1: база знань містить дев'ять правил, а механізм прямого виведення використовує FIFO-чергу та показує ланцюг спрацьованих правил.

## Відкриття локально

Відкрийте `index.html` у браузері. Сервер і додаткові бібліотеки не потрібні.

## Публікація на GitHub Pages

1. Завантажте файли репозиторію на GitHub.
2. Відкрийте `Settings` → `Pages`.
3. У розділі `Build and deployment` виберіть `Deploy from a branch`.
4. Виберіть гілку `main`, теку `/ (root)` і натисніть `Save`.

Після публікації сайт буде доступний за адресою `https://ІМʼЯ.github.io/НАЗВА-РЕПОЗИТОРІЮ/`.

## Перевірка

```powershell
node app.test.js
```

Тести охоплюють три основні приклади зі звіту.

## Структура

- `index.html` — структура вебзастосунку.
- `styles.css` — адаптивне оформлення.
- `app.js` — база знань, пряме виведення та взаємодія з користувачем.
- `app.test.js` — автоматичні тести логіки.
